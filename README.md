# Dazaha App 🚚

Dazaha is an Iraqi logistics and delivery mobile application built using Flutter.  
The app connects people who need to transport furniture, deliver items, dispose of waste, or sell used goods with drivers who can complete these tasks.

## 📱 App Features
- Post a delivery or transport request
- Receive offers from drivers
- Compare prices and driver ratings
- Choose the most suitable offer
- Real-time notifications
- In-app chat
- Google Maps integration
- Multi-language support (Arabic)
- User and Driver accounts
- Order tracking

## 🛠️ Technologies Used
- Flutter & Dart
- Firebase (Notifications)
- REST APIs
- Google Maps API
- GetX (State Management)
- Retrofit (API Integration)
- JSON Serialization
- Local Storage
- Push Notifications
